# SideMarks

SideMarksは、よく使うWebページをChromeの右側へ表示する、Google Chrome向けのサイドパネル型ブックマークです。

登録したページをジャンルやフォルダで整理し、現在のタブですばやく開けます。ブックマークや設定はChrome内へ保存されます。

## インストール

1. 配布された`SideMarks`フォルダを、今後移動・削除しない場所へ保存する
2. Chromeで`chrome://extensions`を開く
3. 右上の「デベロッパー モード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」を押す
5. `manifest.json`が入っている`SideMarks`フォルダを選ぶ
6. 必要に応じてSideMarksをChromeのツールバーへ固定する

ツールバーのSideMarksアイコンを押すと、右側にサイドパネルが開きます。

初回起動時に「グラブル向けテンプレート」または「空の状態で始める」を選択します。テンプレートにはグラブルと普段使い向けのブックマーク、標準アイコン、ジャンル・フォルダ、配色と表示設定が含まれます。空の状態ではブックマークやジャンルを登録せずに開始します。どちらにも背景画像と背景プリセットは含まれません。

初回起動時には簡単な使い方が自動表示されます。一度閉じた後も、画面右上の`？`から機能と設定内容をいつでも確認できます。

> 読み込み後もSideMarksフォルダは必要です。フォルダを移動・削除すると再読み込みできなくなるため、移動する場合は先にJSONバックアップを作成してください。

## 基本的な使い方

- 追加：上部の「現在のページを追加」を押す
- 開く：登録したページのタイトルを押す
- お気に入り：ブックマーク右側の星を押す
- 編集：ブックマーク右側の`•••`を押す
- 削除：ブックマーク右側のごみ箱を押す
- 並べ替え：ブックマークをドラッグして移動する
- フォルダ間移動：ブックマークを移動先のフォルダ名またはフォルダ末尾へドロップする
- 元に戻す：画面左上の矢印を押す

上部の検索欄では、地球／再生アイコンのトグルでWeb検索とYouTube検索を切り替えられます。通常時は現在のタブで開き、Chromeの分割表示中は検索先の横にある「左」「右」から開く側を選択します。検索先と左右の選択は次回以降も維持されます。

一覧見出しの「おすすめ」を開くと、Chromeでよくアクセスする未登録サイトを`＋`で追加できます。

ジャンル名の右側にある表示切替ボタンから、そのジャンルだけをタイル表示またはアイコン表示にできます。タイル表示は四角いアイコンとサイト名を並べ、見出し横の「−／＋」で1～6列を選択できます。列数に合わせてタイル、アイコン、文字配置が自動調整されます。アイコン表示も同じボタンで表示数を変更でき、アイコンサイズは自動調整されます。並べ替えやフォルダ移動はどちらでも利用できます。

歯車の「操作感」では、表示切替時の動きを「なし・フェード・横からスライド・ふわっと拡大・順番に表示」から選択できます。

歯車の「操作ボタン」では、タイル／アイコン表示でブックマークに重ねたときの操作ボタンを右上または右下へ配置できます。

操作音は「木琴風・水滴風・ガラス風・電子音・クリック音」から選択でき、選択時に試聴できます。

ブックマークの操作スタイルは「リフト・スライド・チルト・スポット・アイコン・インバート」から選べます。カードを動かす、傾ける、周囲を控えめにする、アイコンだけを動かす、配色を反転するなど異なる表現を用意しており、効果量は「弱・中・強」で調整できます。
設定内のライブプレビューでは、ブックマークの透明度、操作スタイル、操作音、操作ボタンの表示位置をその場で確認できます。

SideMarksアイコンやWebページを右クリックして、現在のページを追加することもできます。

Chromeの分割表示欄は常に左側・右側を表示し、通常表示か分割表示中かを中央で確認できます。分割中は枠全体と操作中の側をテーマカラーで強調します。別のタブを見ている間も「分割あり」と左右のページ名が残り、クリックして分割ペアへ戻れます。この状態表示は設定からON/OFFできます（Chrome 140以降）。Chromeの拡張機能APIは分割状態の確認のみ対応しているため、分割の開始・結合・解除はChrome本体で操作します。

## 整理方法

### ジャンル

画面上部のタブです。「仕事」「趣味」など、表示内容を大きく分けるために使います。

- `＋`でジャンルを追加
- ジャンルタブをドラッグして並べ替え
- ジャンル名をダブルクリックして名前を変更
- ジャンル名右側の`×`で削除
- ジャンル名右側の表示切替ボタンでタイル／アイコン表示を変更
- ブックマーク編集から、用途別に分類された標準アイコンまたは好きな画像を設定。グラブル用アイコンは専用分類から選択
- お気に入りはジャンルをまたいで表示

### フォルダ

各ジャンル内のブックマークを、さらに細かくまとめるために使います。

- ブックマークの編集画面からフォルダを選択・作成
- フォルダ名横の鉛筆ボタンで名前を変更
- フォルダ見出しを押して折りたたみ・展開
- ブックマークをドラッグし、移動先フォルダの末尾へドロップして移動
- フォルダ見出しをドラッグして順番を変更

### 複数選択

一覧上部の「複数選択」から、複数のブックマークに対してジャンル、フォルダ、お気に入りをまとめて変更できます。一括削除にも対応しています。

## 表示のカスタマイズ

右上の画像ボタンから、背景画像と表示位置・拡大率・透明度を設定できます。「すべて」で設定した画像が共通背景になり、お気に入り、未分類、各ジャンルには個別の背景も設定できます。個別背景を設定していない表示では共通背景が使われます。表示を切り替えたときの演出は、クロスフェード、ぼかしフェード、演出なしから選べます。

背景画像からテーマカラー候補を作り、選んだ色をSideMarksの配色へ反映することもできます。

### 背景プリセット

背景設定の「現在の設定を保存」から、背景画像、位置・拡大率・透明度、テーマカラー、ブックマークの透明度・表示スタイルを1つのプリセットとして保存できます。保存後、サムネイルを押すと、現在表示している「すべて」「お気に入り」「未分類」またはジャンルへまとめて適用されます。

- プリセット名は鉛筆ボタンから変更
- ごみ箱ボタンで削除
- サムネイルをドラッグして並べ替え
- 「標準」で初期の背景と配色へ戻す
- 適用後に画像設定や配色を変更すると、プリセット選択状態を解除

歯車設定で背景確認ボタンを表示すると、操作部分を隠して時計と背景を確認できます。同じ位置のボタンをもう一度押すか、Escキーで通常表示へ戻ります。時計は背景確認モードで直接ドラッグでき、位置は自動保存されます。

背景設定の「編集する表示」から、共通・お気に入り・未分類・各ジャンルの背景をまとめて管理できます。「調整値をすべての背景へ反映」を有効にして保存すると、それぞれの画像は維持したまま、表示基準・透明度・拡大縮小・横位置・縦位置を一括で統一できます。

時計はテーマカラーに連動します。背景プリセットには、共通・お気に入り・未分類・各ジャンルの背景と配色をまとめて保存し、一度に切り替えられます。古戦場の日程はジャンル欄の下に表示され、クリックすると直近の日程を展開できます。日程は手動入力できるほか、任意でGameWithへのアクセスを許可し、古戦場ページから日付・時間・属性を取得できます。

右上の歯車ボタンから、次の項目を変更できます。

- テーマカラー
- ブックマークの表示スタイルと透明度
- ブックマークへのテーマカラー適用（古戦場の日程とジャンル欄にも連動）
- 削除ボタンの表示
- ブックマーク操作スタイルと効果の強さ
- ジャンル欄の横移動表示（細いバー・左右ボタン）
- ブックマークとジャンルの操作音、音の種類、音量
- 背景確認ボタンと時計の表示・サイズ

「グラブル用オプション」では、古戦場の日程表示・更新・編集と、ブックマークのHOME設定ボタンを変更できます。

月／太陽ボタンではライトテーマとダークテーマを切り替えられます。

## 開いているタブ

サイドパネル横には、現在のChromeウィンドウで開いているタブがOneNoteのナビゲーションのように常時並びます。通常はアイコンと縦書きの小さなページ名を表示し、上部の三本線を押すと横書きの詳しい表示へ展開します。現在のタブはテーマカラーの枠で示され、クリックで切り替え、中央クリックで閉じられます。タブをドラッグするとChrome本体のタブ順も並び替えられます。分割表示中の2ページには「左」「右」が表示され、操作中の側が強調されます。展開中はピン留め、ミュート、再読み込み、タブを閉じる操作と検索を利用できます。歯車設定からタブ欄の表示・非表示と左右の位置を変更できます。

## Chromeのホームページ設定

歯車設定でHOME設定ボタンを表示し、ブックマーク右側の家アイコンを押すと、そのページのURLをコピーしてChromeの外観設定を開きます。Chromeの仕様により、URL欄への貼り付けは手動で行います。

## バックアップと復元

一覧上部の「データ管理」からバックアップを書き出し、別のChromeや再インストール後のSideMarksへ読み込めます。

- 画像なしバックアップ（軽量）：ブックマーク、標準・カスタムアイコン、ジャンル、フォルダ、表示順、テーマ、背景プリセット名と設定、古戦場の日程を保存（背景画像は除外）
- 完全バックアップ：軽量版の内容に加え、共通・お気に入り・未分類・ジャンル別の背景画像、背景プリセット画像と調整値も保存
- 選択バックアップ：「ブックマークと分類」「表示・操作設定」「背景画像とプリセット」「古戦場日程」から必要な項目だけを選んで保存

データ管理画面では「書き出し」と「読み込み」が別の枠に分かれています。選択バックアップを読み込むと、ファイルに含まれる項目だけが現在の内容から置き換わります。

完全バックアップは背景画像によってファイルが大きくなります。登録URLや個人的な画像も含まれるため、自分の移行・復元用として保管し、他人へ共有する場合は内容に注意してください。

拡張機能を削除する前や、新しいPCへ移行する前にはJSONを書き出してください。

## データと権限

SideMarksは、ブックマークや設定の保存、現在ページの取得、サイドパネルと右クリックメニューの表示、サイトアイコンの取得、Chromeが提供する「よくアクセスするサイト」の表示にChromeの権限を使用します。GameWithから日程を取得する機能を使う場合のみ、初回操作時にGameWithへのアクセス許可を求めます。

保存データは`chrome.storage.local`に置かれます。ユーザー情報の外部送信、Webページの自動操作、ページ内容の書き換えは行いません。GameWithへのアクセスは日程更新ボタンを押した場合だけ実行され、24時間以内の再取得は行いません。

## ほかの人へ共有する場合

プロジェクトフォルダで次のコマンドを実行すると、`manifest.json`のversionを使った配布用ZIPが`dist`フォルダに作成されます。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build-release.ps1
```

例えばversionが`1.24.1`の場合は、`dist\SideMarks-v1.24.1.zip`になります。受け取った人はZIPを展開し、展開後のフォルダをChromeの「パッケージ化されていない拡張機能を読み込む」から選択します。

配布用ZIPにはChrome拡張機能の実行に必要なファイルだけが入り、Git設定、開発用スクリプト、過去のZIPは含まれません。

### GitHub Actionsで作成する

GitHubの`Actions`から`Build release ZIP`を開き、`Run workflow`を押すと、同じ配布用ZIPを手動で生成できます。`Google Driveの固定配布ファイルも更新する`を有効にすると、登録済みのDriveファイルを同じ共有URLのまま更新します。無効にした場合はZIP生成だけを行います。完了した実行結果の`Artifacts`に表示される`SideMarks-vX.X.X`からもダウンロードできます。通常のPushだけでは実行されません。成果物の保存期間は30日です。

拡張機能フォルダには、使用者のブックマークや背景画像は含まれません。データ管理から書き出したJSONには登録URLや設定が含まれ、完全バックアップには背景画像も含まれるため、配布物へ入れないでください。

## 更新方法

SideMarksフォルダを新しいファイルで更新したあと、`chrome://extensions`を開き、SideMarksの再読み込みボタン（円形の矢印）を押してください。通常の更新では保存済みデータは維持されますが、更新前に軽量バックアップを作成しておくと安心です。
