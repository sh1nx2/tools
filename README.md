# SideMarks

SideMarksは、よく使うWebサイトと開いているタブを、Chromeのサイドパネルから操作できる拡張機能です。

ブックマークをジャンルやフォルダで整理できるほか、背景・配色・表示形式を自分好みに変更できます。登録したサイトは新しいタブを増やさず、現在のタブで開きます。

## ダウンロード

**[最新版のSideMarksをダウンロード（Google Drive）](https://drive.google.com/file/d/1wiAbofLyjSaezqzC2ZpSs0Pdqz0Wyjcn/view?usp=drive_link)**

このリンクから常に最新版をダウンロードできます。ダウンロードしたZIPは、使用前に必ず展開してください。

## インストール

1. ダウンロードしたZIPを右クリックし、「すべて展開」を選ぶ
2. 展開した`SideMarks`フォルダを、今後移動・削除しない場所へ置く
3. Chromeで`chrome://extensions`を開く
4. 右上の「デベロッパー モード」をオンにする
5. 「パッケージ化されていない拡張機能を読み込む」を押す
6. `manifest.json`が入っている`SideMarks`フォルダを選ぶ
7. Chromeの拡張機能メニューからSideMarksをツールバーへ固定する

ツールバーのSideMarksアイコンを押すと、右側にサイドパネルが開きます。

> Chromeへ読み込んだ後もSideMarksフォルダは必要です。フォルダを移動・削除すると拡張機能を読み込めなくなります。

## 初めて開いたとき

使い方に合わせて、最初の内容を選べます。

- 一般向けテンプレート（おすすめ）：日常、SNS・交流、動画・音楽、買い物・生活向けの構成
- グラブル向けテンプレート：グラブル用のブックマーク、分類、標準アイコンを含む構成
- 空の状態：何も登録せず、自分で一から作る構成

最初に簡単なチュートリアルが表示されます。閉じた後も、画面右上の`？`からいつでも確認できます。

開始後に別の構成へ変更したい場合は、歯車の「初期設定」からテンプレートを選び直せます。現在のブックマークや表示設定は置き換わるため、必要に応じて先にバックアップしてください。

## 基本操作

- ページを登録：「現在のページを追加」を押す
- ページを開く：登録したブックマークをクリックする
- お気に入り：星ボタンを押す
- 内容を編集：`•••`ボタンを押す
- 削除：ごみ箱ボタンを押す
- 並べ替え：ブックマークを長押ししてドラッグする
- フォルダ間移動：移動先フォルダの中、または末尾へドロップする
- 操作を取り消す：画面左上の戻るボタンを押す

SideMarksアイコンやWebページを右クリックして、現在のページを登録することもできます。

## ブックマークを整理する

### ジャンル

「日常」「仕事」「ゲーム」など、用途を大きく分けるためのタブです。

- `＋`でジャンルを追加
- ジャンルタブをドラッグして表示順を変更
- ブックマークの編集画面から別のジャンルへ移動
- 「お気に入り」では、すべてのジャンルのお気に入りをまとめて表示

### フォルダ

ジャンル内をさらに整理できます。

- ブックマークの編集画面からフォルダを選択・作成
- フォルダ名横の鉛筆ボタンで名前を変更
- フォルダ見出しを押して折りたたみ・展開
- フォルダ見出しをドラッグして表示順を変更
- ブックマークをドラッグしてフォルダ内や別フォルダへ移動

一覧上部の「複数選択」では、複数のブックマークのジャンル、フォルダ、お気に入りを一括変更できます。

## 表示を切り替える

ジャンルごとに、ブックマークの表示方法を選べます。

- タイル表示：アイコンとサイト名を四角く表示
- アイコン表示：アプリのようにアイコン中心で表示
- `−`と`＋`で1～6列に変更

設定では、ブックマークの透明度、ガラス調／フラット表示、操作時の動き、ボタン位置、操作音なども変更できます。設定内の見本へカーソルを合わせたりクリックしたりすると、見た目と音をその場で確認できます。

## 検索とおすすめ

上部の検索欄からWebまたはYouTubeを検索できます。地球／再生アイコンを押すと検索先が切り替わります。

「おすすめ」には、Chromeでよくアクセスしている未登録サイトが表示されます。候補を開いたり、`＋`でSideMarksへ追加したりできます。この情報はChromeが端末内で提供する履歴候補を利用します。

## 開いているタブを操作する

サイドパネルの端に、現在のChromeウィンドウで開いているタブが表示されます。

- クリック：タブを切り替える
- 中央クリック：タブを閉じる
- ドラッグ：Chromeのタブ順を変更する
- 三本線：詳しいタブ表示を開閉する
- 詳細表示：検索、ピン留め、ミュート、再読み込み、タブを閉じる操作

設定から、タブ欄の表示／非表示と左右の位置を変更できます。

Chromeの分割表示を使用している場合は、左右のページがつながった形で表示され、現在操作している側がテーマカラーで強調されます。検索結果を開く側も左／右から選択できます。

> Chromeの仕様上、分割表示の開始・結合・解除はChrome本体で操作します。

## 背景・配色を変更する

画面右上の画像ボタンから背景を設定できます。

- 好きな画像を背景にする
- 画像の拡大率、位置、透明度を調整する
- 「すべて」「お気に入り」「未分類」やジャンルごとに背景を変える
- 背景画像からテーマカラー候補を作る
- 現在の背景と配色をプリセットとして保存・上書きする
- 保存したプリセットを名前変更、並べ替え、削除する

歯車の設定では、テーマカラー、ライト／ダーク表示、ブックマークの透明度や素材、時計、背景確認モードなどを変更できます。

背景確認モードでは操作部分を隠して背景と時計を表示できます。時計はドラッグで好きな位置へ動かせます。

## グラブル用オプション

設定から、必要な場合だけ次の機能を有効にできます。

- 古戦場の日程とカウントダウンの表示
- GameWithからの日程取得
- Chromeのホームページ設定を補助するHOMEボタン

GameWithから日程を取得するときだけ、Chromeがアクセス許可を確認します。取得機能を使わない場合は許可する必要はありません。

画面上部の`◇`から、十天衆・十賢者・終末・ドラポン・破壊武器の育成進捗と優先目標を管理できます。素材入力は必須ではなく、優先目標に必要なものだけ後から確認できます。

- 現在の育成段階だけでも保存可能
- 終末は各属性のマグナ・神石を別々に設定し、全体進捗には高い方だけを反映
- 目標を「最優先・優先・通常」に分類
- 素材所持数は同じ素材を使う複数目標で共有
- 未入力の素材は0個ではなく「未確認」として表示
- 重要素材は数量、一般素材は達成チェックで管理
- 必要素材を「最優先・優先まで・全体」で集計

必要数を確認できていない強化段階には推測値を使用せず、「素材データ未登録」と表示します。

## バックアップと復元

一覧上部の「データ管理」から、設定やブックマークをJSONファイルへ保存できます。

- 画像なしバックアップ：ブックマークや設定を保存する小さめのバックアップ
- 完全バックアップ：背景画像と背景プリセットを含めて保存
- 選択バックアップ：保存したい項目だけを選択

グラブル進捗管理の現在段階、優先目標、素材所持数もバックアップへ保存されます。

別のPCへの移行や拡張機能を入れ直す前には、完全バックアップがおすすめです。復元するときは、データ管理の「読み込み」から保存したJSONを選びます。

> バックアップには登録したURLや設定が含まれます。完全バックアップには個人的な背景画像も含まれるため、他人へ渡す場合は内容に注意してください。

## 更新方法

1. 念のため、SideMarksの「データ管理」からバックアップを保存する
2. [固定ダウンロードリンク](https://drive.google.com/file/d/1wiAbofLyjSaezqzC2ZpSs0Pdqz0Wyjcn/view?usp=drive_link)から最新版をダウンロードする
3. ZIPを展開する
4. 現在使用しているSideMarksフォルダ内のファイルを、新しいファイルで置き換える
5. Chromeで`chrome://extensions`を開く
6. SideMarksの再読み込みボタン（円形の矢印）を押す

通常は保存済みのブックマークや設定が維持されます。フォルダの中へさらにSideMarksフォルダを入れる二重構造にはせず、`manifest.json`がこれまでと同じ階層にある状態で更新してください。

現在のバージョンは、SideMarks画面上部または歯車設定の下部で確認できます。

## データと安全性

ブックマークや設定はChrome内の`chrome.storage.local`へ保存されます。SideMarksは、ユーザー情報を外部へ送信したり、開いているWebページを自動操作したりしません。

サイトアイコンの表示、現在のタブの取得、タブ操作、右クリックメニュー、おすすめサイトの表示などに、Chromeが提供する拡張機能の権限を使用します。

## 困ったとき

- 更新が反映されない：`chrome://extensions`でSideMarksを再読み込みする
- 拡張機能を読み込めない：選択したフォルダ直下に`manifest.json`があるか確認する
- 突然使えなくなった：読み込み時に選んだSideMarksフォルダが移動・削除されていないか確認する
- 設定を元へ戻したい：歯車設定の「初期設定に戻す」を使用する
- 新しいPCへ移したい：元のPCで完全バックアップを保存し、新しいPCで読み込む
